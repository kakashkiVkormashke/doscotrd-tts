# Discord TTS Bot

Бот озвучивает сообщения только из канала `1428896474611187734`. Историю не читает, команды не нужны: пользователь заходит в голосовой канал и пишет текст в TTS-канал, бот удаляет исходное сообщение, генерирует русскую озвучку через gTTS, заходит в голосовой канал автора, проигрывает аудио и выходит, когда очередь пустая.

## Discord

1. Создайте приложение и бота в https://discord.com/developers/applications.
2. На странице Bot включите `Message Content Intent`.
3. Пригласите бота с правами `View Channel`, `Send Messages`, `Manage Messages`, `Connect`, `Speak`.
4. Дайте боту доступ только к нужному текстовому каналу и нужным голосовым каналам.

`Manage Messages` нужен, чтобы удалять сообщения после озвучки. Если права нет, бот продолжит работать, но сообщения останутся в канале.

## Переменные окружения

```text
DISCORD_TOKEN=токен_бота
TTS_CHANNEL_ID=1428896474611187734
MAX_TEXT_LENGTH=450
```

Токен не публикуйте в GitHub и не отправляйте в чат.

## Хостинг

Для Bothost используйте ветку `main` и включите запуск через собственный `Dockerfile`, если такая настройка есть. Dockerfile ставит Python 3.11, FFmpeg и libopus.

Если запускаете без Docker, на сервере должны быть Python 3.11 и FFmpeg в `PATH`.

```bash
python -m pip install -r requirements.txt
python -u main.py
```

Бот использует gTTS, поэтому серверу нужен исходящий доступ к сервисам Google TTS и Discord voice.

## Проверка

Проверьте после запуска:

- сообщение в другом канале игнорируется;
- сообщение в TTS-канале без голосового канала даёт подсказку;
- обычное сообщение удаляется и озвучивается;
- несколько сообщений подряд проигрываются по очереди;
- длинный текст отклоняется по лимиту `MAX_TEXT_LENGTH`.
